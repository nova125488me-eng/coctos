# CACTUS VPN — Telegram Mini App (Initial)

این نسخه، اسکلت اولیه رابط کاربری بر اساس تصویر مرجع است.

## فایل‌ها
- `index.html` — ساختار صفحه
- `style.css` — طراحی کامل و واکنش‌گرا
- `script.js` — منطق اولیه و آماده‌سازی برای Telegram WebApp
- `assets/` — محل لوگو، تصاویر و آیکون‌های واقعی

## اتصال نسخه بعدی
برای وصل کردن موجودی و خریدها به ربات:
1. Backend/API به پروژه اضافه می‌شود.
2. Telegram WebApp `initData` در سمت سرور اعتبارسنجی می‌شود.
3. Telegram user_id به حساب کاربر ربات وصل می‌شود.
4. موجودی، سفارش‌ها، سرویس‌ها و تراکنش‌ها از دیتابیس مشترک خوانده می‌شوند.
5. دکمه‌های خرید به API ربات/پرداخت متصل می‌شوند.

نکته امنیتی: توکن BotFather هرگز داخل JavaScript یا فایل‌های فرانت‌اند قرار نگیرد؛ فقط روی سرور و در Environment Variables نگهداری شود.
